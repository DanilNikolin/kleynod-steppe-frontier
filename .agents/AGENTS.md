# Workspace Agent Rules

- **Создание файлов без описания кода**: Если Пользователь просит создать файл и не прикладывает конкретный код/требования к реализациям, создается пустой файл (или базовый заголовок `class_name` / `extends` для GDScript), так как Пользователь сам вставит туда код.
- **Запрос ссылок на файлы**: Если Пользователь просит "дай ссылку на <path>" (например, `res://path/to/file.gd`), сразу отсылаем кликабельную markdown-ссылку на этот файл без вызовов инструментов, анализа кода и траты токенов.
- **Автоматический Git Push**: При выполнении любого коммита по запросу Пользователя обязательно сразу пушить изменения в удаленный репозиторий GitHub (`git push origin <branch>`).
